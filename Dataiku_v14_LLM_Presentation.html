Section 4 — Tokens, Security & Cost

Understanding Tokens

What is a token?

A token is the smallest unit of text an LLM reads. Roughly ¾ of a word or 4 characters.

"Hello, how are you today?"
 ↓ tokenised as ↓
[Hello] [,] [how] [are] [you] [today] [?]
= 7 tokens

Two types you pay for

Prompt (Input)
↑ IN
System prompt + user message + history + context
Completion (Output)
↓ OUT
The model's generated response

💡 Cost Formula

Cost = (prompt_tokens × Pin)
      + (completion_tokens × Pout)

Section 4 — Tokens, Security & Cost

Security & Cost Control in Dataiku v14

🔒 Security Layer

Risk API key exposure  →  Keys stored encrypted in Dataiku Connections
Risk PII sent to cloud LLM  →  Guardrails: PII Detection blocks/masks before send
Risk Prompt injection  →  Guardrails: Prompt Injection Detection
Risk Data residency  →  Use Azure EU / Bedrock / local HF
Risk Unauthorised model use  →  Connection-level group permissions

💰 v14 Cost Control Features

  • LLM Quotas — Max tokens per user/group per day or week (Admin → LLM → Quotas)
  • Rate Limiting — Throttle requests/second to avoid provider 429 errors
  • Cost Visibility — Per-project, per-model cost breakdown for admins
  • $0 exemption — Free queries bypass quota (v14.2+)
  • Prompt Studio — Shows live cost per run before you scale
  • Audit Logs — Every LLM call logged: who, what model, how many tokens

💡 Rule of Thumb

A typical RAG query (2k prompt + 500 output tokens on GPT-4o mini) ≈ $0.000075 per call. At 10,000 calls/day = $0.75/day.

Section 5 — Live Code Examples

Example 1: Basic Chat Completion

No third-party SDK needed — use the dataiku package available in every Dataiku code environment.

import dataiku

# Step 1: Get an LLM handle (format: "connection_name:model_id")
client = dataiku.api_client()
llm    = client.get_llm("openai:gpt-4o")

# Step 2: Build the query
query = llm.new_completion()
query.with_message("You are a helpful data analyst assistant.", role="system")
query.with_message("Explain what a vector embedding is in 2 sentences.")

# Step 3: Execute and read the response
response = query.execute()

print(response.text)
print(f"Prompt tokens    : {response.usage['prompt_tokens']}")
print(f"Completion tokens: {response.usage['completion_tokens']}")
print(f"Total tokens     : {response.usage['total_tokens']}")

✅ Output

A vector embedding is a list of floating-point numbers that captures the semantic meaning of text, where similar texts produce vectors that are mathematically close together in high-dimensional space.

Prompt: 42 | Completion: 38 | Total: 80

💡 Key points

  • LLM ID format: "connection:model"
  • System prompt sets behaviour
  • Token counts returned per call
  • No API key in your code — ever

Example 2: Embeddings & JSON Mode

Embedding Generation

import dataiku

embed_llm = client.get_llm("openai:text-embedding-3-large")

query = embed_llm.new_embeddings()
query.add_text("quarterly revenue review")
query.add_text("AI Factory deployment pipeline")

resp = query.execute()

for emb in resp.get_embeddings():
    print(f"Vector: [{emb[0]:.4f}, {emb[1]:.4f}, ...]")
    print(f"Dims  : {len(emb)}")
Output: [0.0234, -0.1412, 0.8891, ...] (1536-dim)

Structured JSON Output

import json

llm = client.get_llm("openai:gpt-4o-mini")
q   = llm.new_completion()
q.with_message("Reply with valid JSON only.",
               role="system")
q.with_message("Extract: company, year, revenue from: "
               'Acme Corp reported $4.2M in 2025.')

# Enable JSON mode
q.settings["responseFormat"] = {"type": "json_object"}

resp   = q.execute()
parsed = json.loads(resp.text)
print(parsed)
Output:
{"company": "Acme Corp", "year": 2025, "revenue": 4200000}
Section 5 — Live Code Examples

Example 3: Multi-turn Conversation (v14.5+)

import dataiku

client  = dataiku.api_client()
llm     = client.get_llm("openai:gpt-4o")

# ── Turn 1 ──────────────────────────────────────────────────
q1 = llm.new_completion()
q1.with_message("You are a concise Dataiku expert.", role="system")
q1.with_message("What is a Knowledge Bank in Dataiku?")
r1 = q1.execute()

print("Turn 1:", r1.text)

# ── Turn 2: use prepare_followup() — new in v14.5 ───────────
q2 = r1.prepare_followup()   # automatically carries conversation history
q2.with_message("How do I build one from PDF documents?")
r2 = q2.execute()

print("Turn 2:", r2.text)

🆕 prepare_followup() — v14.5

  • Automatically carries previous messages into the next query
  • No manual history management needed
  • Works with streamed responses too: execute_streamed(collect_response=True)

🤖 Prompt Recipe (No-code batch)

  • Flow → Add Recipe → Gen AI → Prompt
  • Runs LLM on every row of a dataset
  • Use {{column_name}} in prompt templates
  • Shows live cost estimate before you run

Section 6 — Common Errors

Production-Grade Error Handling Pattern

import time, dataiku

def call_llm_with_retry(llm_id, system_prompt, user_prompt, max_retries=3):
    client = dataiku.api_client()
    llm    = client.get_llm(llm_id)

    for attempt in range(1, max_retries + 1):
        try:
            q = llm.new_completion()
            q.with_message(system_prompt, role="system")
            q.with_message(user_prompt)
            return q.execute().text

        except Exception as e:
            err = str(e).lower()

            if "401" in err or "unauthorized" in err:
                raise RuntimeError("Auth failed — ask admin to check API key.") from e

            elif "context_length" in err:
                raise ValueError("Prompt too long — chunk document or use 128k model.") from e

            elif "429" in err or "rate_limit" in err:
                wait = 2.0 * (2 ** (attempt - 1))  # exponential back-off
                print(f"Rate limit — waiting {wait}s...")
                time.sleep(wait)

            else:
                raise   # unknown — don't swallow

    raise RuntimeError("All retries exhausted.")

✅ Pattern Summary

401 → raise immediately token limit → re-chunk 429 → exponential backoff timeout → retry unknown → re-raise (don't hide)

Section 8 — Things to Remember

Pre-Project Checklist

Before you start building

Confirm which LLM connections are available (ask admin)
Understand data residency requirements (EU? on-prem?)
Agree on model for each step (embed ≠ complete ≠ rerank)
Estimate token counts & monthly cost before scaling
Never hard-code API keys — always use Dataiku connections
Test in Prompt Studio before building a Flow recipe
Enable Guardrails for customer-facing applications

Token Golden Rules

A4 page → tokens~500–700
