Business Context

The problem we're solving

Who

Priority Customers (PC) who already hold an investment product (unit trust, structured note, bonds, equities, or ILP insurance).

What RMs need

A concrete, data-grounded "who is this client segment" narrative and a 6-month engagement plan with specific product recommendations — not generic upsell scripts.

Why it's hard

  • Thousands of clients per RM book — needs to happen at cluster level, not per-client.
  • Recommendations must be traceable to real data, not hallucinated.
  • Output must read like a senior analyst wrote it — nuanced, specific, banking-fluent.

Approach

Segment clients via GMM clustering on a behavioural/financial feature set, then use an LLM to translate each cluster's statistical profile into a narrative + RM action plan + product picks.

V1

Where V1 fell short

No sense of what's distinctive

Every feature was presented flat — the LLM had no signal for which of the ~100 values actually define this cluster versus the rest of the base.

No cohesion awareness

A tight, homogeneous cluster and a mixed, bimodal one were treated identically — no hedging language for unreliable segments.

No commercial sizing

Opportunity was described only in ratios/percentages ("41% off-us") — never translated into an actual MYR business case for prioritisation.

Monolithic prompt

One persona covering data science, RM strategy, and marketing tone led to inconsistencies — e.g. product_name vs product_id conflicts in the schema.

V2

Where V2 still falls short

Still one persona doing four different jobs

A single prompt is asked to simultaneously be a statistical profiler, a commercial risk analyst, an RM strategist, and a marketing copywriter — in one pass, with no review step.

  • No mechanism to catch an invented or mis-cased product ID before it reaches an RM.
  • No check that every narrative claim actually traces back to a real data point.
  • No self-correction — if the output is weak, it's weak; there's no critique-and-revise step.
  • Quality still depends entirely on one generation pass getting everything right at once.

V3

The Feedback Loop, in detail

Critic checks, not vibes

  • Numeric grounding — every claim cites a real value, no vague placeholders
  • Signal traceability — distinguishers map to actual W1/opportunity signals
  • Product eligibility — recommended IDs exist in the product dictionary
  • Cross-phase consistency — Month 1–2 and Month 5–6 don't contradict
  • Tone rules — numeric phrasing & sentence-starter rules enforced
  • Urgency-rationale match — "High" urgency is backed by the actual $ figures

Targeted routing, not blanket retry

Each issue is tagged with its owning agent. Only that agent revises — the other three outputs stay untouched, keeping fixes cheap and precise.

Bounded & safe

  • Max 2 revision rounds — no infinite loops
  • Hard failures block pass; soft warnings pass through with a note
  • Unresolved clusters are flagged for human review, not silently dropped

def load_profile(dataset_name="INVESTMENT_PROFILE_PC"):
    df = dataiku.Dataset(dataset_name).get_dataframe()
    df = df.set_index(df.columns[0]).T          # rows -> one cluster per row
    df.index.name = "cluster_label"
    return df

def load_product_dictionary(folder_name="MFU"):
    folder = dataiku.Folder(folder_name)
    filepath = [f for f in folder.list_paths_in_partition() if f.endswith(".yaml")][0]
    with folder.get_download_stream(filepath) as f:
        product_dict = yaml.safe_load(f)
    return product_dict["products"]

def load_all_signal_blocks(...):
    return {
        "profile_df": load_profile(...), "sharp_signals_df": load_sharp_signals(...),

        "opportunity_sizing_df": load_opportunity_sizing(...), "tail_profile_df": load_tail_profile(...),
        "all_products": load_product_dictionary(...),
    }

def extract_profile_block(profile_df, cluster_id):
    row = profile_df.loc[f"Cluster {cluster_id}"]
    features = {f: _clean_value(v) for f, v in row.items() if f not in PROFILE_HEADER_COLS}
    return {"n_clients": int(row["n_clients"]), "pct_%": row["pct_%"], "features": features}

def build_cluster_context(cluster_id, loaded_data, run_id, partition=None):
    profile_block = extract_profile_block(loaded_data["profile_df"], cluster_id)
    return {
        "cluster_id": cluster_id, "run_id": run_id, "partition": partition,
        "profile": profile_block,
        "sharp_signals": extract_sharp_signals_block(loaded_data["sharp_signals_df"], cluster_id),
        "shape": extract_shape_block(loaded_data["cluster_shape_df"], cluster_id),
        "topology": extract_topology_block(loaded_data["cluster_topology_df"], cluster_id),
        "opportunity": extract_opportunity_block(loaded_data["opportunity_sizing_df"], cluster_id),
        "tail": extract_tail_block(loaded_data["tail_profile_df"], cluster_id),
        "eligible_products": filter_eligible_products(loaded_data["all_products"], profile_block),
    }

while round_count < max_rounds:
    critic_output = critic_review(llm, ctx, *outputs.values())
    if critic_output["verdict"] == "pass" or not critic_output["issues"]:

    return {"ok": len(errors) == 0, "errors": errors}
